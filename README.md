# 탐구 전략 사전

개념 기반 탐구의 47가지 전략을 수업 준비·진행·학생 반응·이해 확인·후속 활동까지 안내하는 초등 교사용 웹앱입니다.

- 사이트: https://knightayj52.github.io/inquiry-strategies/
- 7개 수업 상황별 전략 찾기와 기존 단계별 검색
- 47개 전략별 준비 자료·예상 시간·후속 발문·다음 학습 안내
- 대표 전략 5개의 가상 자료, 진행표, 작성 예시, 반응별 지도와 인쇄용 학생 활동지
- 자료가 차시 사이에 이어지는 사회·창체 8차시 구성 예시
- 성취기준 600개와 규칙 기반 6·8·10차시 초안: 개념·질문·자료·전략 수정, 브라우저 저장, 텍스트 복사

## 구성과 실행

`index.html`, `classroom.js`, `classroom.css`, `appearance.js`, `interface.js`, `interface.css`, `visuals.js`, `visuals.css`를 같은 폴더에 둡니다. 정적 서버 또는 GitHub Pages에서 실행하며 별도의 빌드나 서버 API가 필요하지 않습니다. 로컬에서는 `python -m http.server 8000` 후 `http://localhost:8000`을 열 수 있습니다. 수정 초안은 해당 브라우저의 localStorage에만 저장됩니다.

## 화면과 배경 설정

수업 상황과 탐구 단계 선택을 분리하고, 전략 상세는 한눈에·수업 진행·자료/예시·지도/평가의 네 영역으로 제공합니다. 탐구 고리의 중앙에는 전 과정에 걸친 성찰을 표시합니다. 교사 안내 전체 인쇄에는 현재 숨긴 영역도 포함됩니다.

상단의 **화면 설정**에서 세이지·크림·하늘·로즈·라벤더·화이트·다크 또는 기기 설정을 선택할 수 있습니다. 색상 선택기와 6자리 HEX 코드로 사용자 배경도 지정할 수 있습니다. 배경에 맞춰 글자·카드·강조색의 대비를 조절하고, 설정은 해당 브라우저의 localStorage에 저장합니다. 저장 불가 시 현재 화면에는 적용하고 비영속 상태를 안내합니다. 학생 이름이나 수업 기록을 전송하지 않습니다.

## 수업 시각화

전략 카드의 **과정 시각화** 표시 또는 상세 화면의 **그림으로 따라보기**에서 접근합니다. 교차 비교표, 개념 획득, 일반화 다듬기, 보기–생각하기–궁금해하기, 프레이어 모델, 네 모퉁이, 새 사례에 적용·검증, 전문가 모둠의 8개 전략에 완성 예시·과정 따라가기·빈 양식을 제공합니다.

- 비교표: 질문 하나씩 보기/전체 표, 근거 번호와 관계 문장 연결
- 개념 획득: 예·비예시 순차 공개, 잠정 가설 수정과 새 카드 판별
- 일반화: 처음 문장·근거·조건·수정 문장 연결
- 다른 5개 전략: 관찰/해석/질문, 개념의 네 영역, 학생 위치 변화, 전이 판단, 전문가/원모둠 이동 시각화
- 빈 양식은 입력·보기 전환·닫기 후에도 현재 페이지에서 유지되며 새로고침 시 사라집니다. 학생 정보는 저장하거나 전송하지 않습니다.
- 현재 보기와 빈 양식/입력 내용 인쇄를 지원합니다. 전체 교사 안내 인쇄는 현재 단계와 관계없이 완성 예시를 포함합니다.

`tests/visuals.cjs`에서 8개 전략의 세 보기, 이전/다음 경계, 근거 선택, 도형 공개, 이동 구조, 입력 유지/삭제, 안전한 텍스트 표시, 인쇄, 키보드, 320px·390px 화면과 다크 모드를 점검합니다.

## 자료의 성격

적용 자료와 학생 응답은 개발자가 구성한 가상 예시입니다. 실제 수업 효과가 검증된 사례로 표시하지 않습니다. 원전의 핵심 취지와 개발자의 운영 제안을 구분하며, 공식 자료 링크를 전략별로 제공합니다. 교육과정 데이터와 도서 전체를 이번 개정에서 모두 대조한 것은 아닙니다. 자동 설계안은 교사가 자료·맥락·학생 이해에 맞게 조정할 초안입니다.

교차 비교표 방향, 일반화의 조건과 반례, QFT 원형과 추가 분류, 관찰·해석 구분, 분수의 수와 실제 양 구별 등을 2026-10-28 개정에서 수정했습니다. 성찰을 포함한 자동 차시 시간은 차시당 40분입니다.

## 확인

`node --check classroom.js`로 추가 스크립트를 확인할 수 있습니다. `tests/classroom.cjs`는 Playwright를 사용하여 전체 전략·상황 검색·설계 수정과 저장·40분 배분·인쇄·모바일 화면을 점검합니다. 실행 환경에 Playwright와 Chromium이 필요합니다. `tests/interface.cjs`는 탐색 전환, 네 영역 이동, 모든 영역 인쇄, 배경 선택/저장/입력 검증, 시스템 모드 변경, 대비, 320px·390px 모바일 화면, 저장 차단 상황을 점검합니다. 두 테스트는 임시 로컬 HTTP 서버를 직접 시작합니다. 자세한 실행 옵션은 테스트 파일 상단을 참고하세요.
